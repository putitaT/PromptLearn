PromptLearn Backend API

Build and publish a syllabus, review student work with guided questions, or publish lesson recordings for replay.

Local base URL http://127.0.0.1:8080

Download OpenAPI 3.0.3

How the endpoints fit together

  1. Choose row IDs from the curriculum and check class capacity with timetable availability.
  2. Send the selected rows and period count to draft generation.
  3. Edit the plan and use preview to verify periods, assessment points, and dates.
  4. Save the draft, then publish it. Students read the latest published view.

In an edited plan, assessment period numbers start at 1 within each unit. Responses number periods across the entire semester. HTML strings in examples are shortened.

For video replay, upload an MP4 for transcription, preview the draft as a teacher, then publish it for student replay. Try the flow with curl.

Check assignment work

Send the assignment and item IDs, OCR blocks, and paper photo to assignment review. Draw each returned highlight from its original OCR box. Clear highlights for correct or unreadable work.

Check the student's reasoning on one assignment item

POST/v1/assignments/{assignment_id}/items/{item_id}/reviews

Local demo for HW 3.1 (q1, q2, q3, q5) and the original HW 3.2 example (q4). The backend loads the private question and rubric. Flutter sends the full paper PNG as a Base64 data URL. In OpenAI mode, if the client omits OCR blocks, the backend measures ink rows on the original image and transcribes them. The image-only path is designed for dark handwriting on the light Flutter notebook with rows in one column. Clients that already perform OCR can send positioned blocks in reading order and the same image used to find their boxes. Use issue boxes as fractions of the full image, measured from the top-left corner. The response does not include an annotated image. The request body limit is 5 MiB. Each completed review is saved as feedback on the in-progress attempt.
