# หน้าทำการบ้านและการตรวจวิธีทำ

## ทดลองบน Android Emulator

เข้าสู่ระบบเป็น Student แล้วแตะ **HW 3.1 · Exponent practice** ในส่วน **All Homework** ของหน้า Home เริ่มจากข้อ 1 บนกระดาษเปล่า ใช้ลูกศรซ้าย ขวา หรือปุ่มหมายเลขเพื่อเปลี่ยนข้อ ฝั่ง Teacher ใช้หน้า Courses เดิม

- ใช้ปากกาเขียน ไฮไลต์ หรือลบเส้น ยางลบแสดงขอบบริเวณที่กำลังลบและซ่อนทั้งเส้นทันทีที่สัมผัส ใช้ Undo เพื่อย้อนการลากยางลบหนึ่งครั้ง และ Redo เพื่อทำซ้ำ
- ใช้สองนิ้วจีบหรือถ่างเพื่อซูมตั้งแต่ 1× ถึง 4× เมื่อซูมแล้วใช้หนึ่งนิ้วเลื่อนกระดาษได้ การซูมและเลื่อนไม่เริ่ม Automatic Checker และ Snap จะจับภาพกระดาษเต็มแผ่น
- **Snap paper work** จับภาพกระดาษและเรียกตัวตรวจหนึ่งครั้ง เมื่อเปิด **Automatic Checker** แอปรอ 2.5 วินาทีหลังยกปากกาหรือจบการแก้ไข การเขียนต่อจะเริ่มนับเวลาใหม่ ค่าเริ่มต้นของ Automatic Checker คือปิด
- เมื่อกำหนด API base URL ตัวตรวจจะส่งกระดาษไปยัง Go backend กระดาษแต่ละข้อเริ่มว่างและอยู่ในหน่วยความจำระหว่างการล็อกอินเดียวกัน
- คำใบ้แสดงร่วมกับแถบไฮไลต์สีแดงอ่อนโปร่งใสบนขั้นที่ต้องทบทวน โดยแถบไฮไลต์อยู่คนละชั้นกับภาพที่ส่งตรวจ

ปุ่ม **Submit** เปิดใช้เมื่อเขียนครบ 4 ข้อ แอปตรวจจากกระดาษของทุกข้อและใช้ผลตรวจเดิมเมื่อฉบับกระดาษตรงกัน เมื่อ Go บันทึกผลแล้ว แอปเปิดหน้า **My progress** พร้อมคะแนนรายข้อและรายการข้อผิด กด **View results** เพื่อกลับมาดูผลขณะอยู่ในเซสชันเดิม

เลื่อนที่บริเวณโจทย์หรือขอบกระดาษเพื่อดูเนื้อหาด้านล่าง ชื่อการบ้าน ปุ่มย้อนกลับ และปุ่มแจ้งเตือนอยู่ด้านบนระหว่างเลื่อน

## เชื่อมกับ Go backend

ในโฟลเดอร์ `backend/` โหลดคีย์จาก `.env` ที่เตรียมไว้และเปิดโหมดตรวจจากภาพ

```sh
set -a
source .env
set +a
HTTP_ADDR=127.0.0.1:8080 ASSIGNMENT_REVIEW_MODE=openai go run ./cmd/server
```

ต่อ Android Emulator หรือแท็บเล็ตที่เปิด USB debugging จากนั้นรันใน `frontend/` โดยแทน `<device-id>` ด้วยรหัสจาก `adb devices` ใช้การส่งต่อพอร์ตเพื่อให้ API เดโมรับเฉพาะ loopback

```sh
adb -s <device-id> reverse tcp:8080 tcp:8080
flutter run -d <device-id> --dart-define=PROMPTLEARN_API_BASE_URL=http://127.0.0.1:8080
```

เมื่อเว้น `PROMPTLEARN_API_BASE_URL` แอปใช้ตัวตรวจจำลองใน Flutter เมื่อใช้ backend โหมด `mock` การตรวจจากภาพอย่างเดียวจะแจ้งว่าอ่านไม่ชัด การลอง OCR และไฮไลต์จากลายมือใช้โหมด `openai`

## รูปแบบการส่งกระดาษและผลตรวจ

1. **Flutter** ส่ง PNG ทั้งกระดาษใน `image_data_url` แบบ Base64 JSON ไปที่ `POST /v1/assignments/hw-3-1/items/q1/reviews` เปลี่ยนรหัสข้อเป็น `q1` ถึง `q8` ตามหน้าที่เปิดอยู่
2. **Go** ดึงโจทย์และเกณฑ์ด้วยรหัสใน URL เมื่อคำขอไม่มี OCR ระบบวัดตำแหน่งหมึกในภาพแล้วให้โมเดลอ่านข้อความทีละบรรทัด จากนั้นตรวจวิธีทำและบันทึก feedback ก่อนตอบกลับ
3. **ผลตรวจ** ใช้ `status` และ `issues` เมื่อ `needs_revision` แต่ละจุดมี `box`, `observation` และ `hint` เมื่อ `correct` หรือ `unreadable` ระบบส่ง `issues: []`
4. **การวาด** พิกัด `{x, y, width, height}` เป็นสัดส่วน 0–1 ของ PNG ทั้งแผ่นจากมุมซ้ายบน Flutter วาดแถบสีที่ซูมตามกระดาษและทิ้งผลเก่าหากแก้วิธีทำหรือเปลี่ยนข้อ

เมื่อกด **Submit** แอปส่ง `review_ids` ครบทั้ง 4 ข้อไปที่ `POST /v1/assignments/hw-3-1/submissions` Go บันทึกผลจาก OCR พิกัดและคำใบ้ แล้วคำนวณคะแนนระหว่างเรียนจากผลตรวจ ข้อถูกได้เต็ม ข้อที่ต้องแก้ได้ 0 และข้อที่อ่านไม่ชัดขึ้น Pending [ตัวอย่าง JSON ใน API Reference](../backend/api-spec/index.html#submitReviewedHomework)
